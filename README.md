Persönlicher Arbeitsraum für Akquise, Projekte, Lernen und ausgewähltes Wissen mit Freigaben für externe Aktionen.

## Projekt und Beitrag

Portfolio-Arbeitsprobe von Adrien Wottke, Maschinenbaustudent mit Interesse an Engineering, Software und praktischen KI-Anwendungen. Der gezeigte Stand entstand unter Einsatz von KI-Werkzeugen. Vorgefertigte Frameworks und Drittanbieter-Komponenten bleiben Beiträge ihrer jeweiligen Urheber.

**Technologien:** Next.js, TypeScript, Prisma, PostgreSQL, PGlite.

## Einstieg

```sh
npm ci
npm run dev
```

Benötigte Zugänge und Dienste müssen mit eigenen Werten eingerichtet werden. Diese Kopie enthält keine Zugangsdaten und verbindet sich nicht automatisch mit einer bestehenden Betriebsdatenbank. Vor dem Start Konfiguration und Paket-Skripte prüfen.

Lokale Demo mit synthetischen Daten; keine persönlichen Gesprächsprotokolle oder Obsidian-Inhalte enthalten. Technische Umsetzung belegt keinen Produktivitäts- oder Geschäftserfolg. KI-Werkzeuge unterstützten die Entwicklung.

Snapshot für Bewerbungen vom 25. Oktober 2026. Der Upload ist kein neuer Funktions-, Leistungs- oder Live-Nachweis. Die Originalprojekte werden unabhängig weiterentwickelt; diese Kopie synchronisiert sich nicht automatisch.
